# رفع اشکال افزونه Paasta

## پروژه‌ها نمایش داده نمی‌شوند

- `Paasta: ورود امن` و سپس `Paasta: تازه‌سازی پروژه‌ها` را اجرا کنید.
- مطمئن شوید فضای کاری درست در کنسول فعال است.
- اگر Token لغو شده، یک بار خارج و دوباره وارد شوید.

## `paasta` پیدا نمی‌شود

در ترمینال VS Code دستور `paasta version` را اجرا کنید. اگر پیدا نشد، CLI را نصب و VS Code را کامل ببندید و دوباره باز کنید تا PATH تازه بارگذاری شود. برای CLI با مسیر اختصاصی، `paasta.cliPath` را روی مسیر کامل executable قرار دهید.

## Cost Preview یا Deploy وارد حساب نیست

ورود افزونه و CLI مستقل‌اند. `paasta login` و سپس `paasta whoami` را اجرا کنید. این جداسازی مانع ورود Token افزونه به Process یا Environment ترمینال می‌شود.

## لاگ با خطای نمونه جایگزین‌شده باز نمی‌شود

هنگام Rollout ممکن است نمونه قبلی حذف شده باشد. چند ثانیه صبر کنید، View را Refresh و دوباره Logs را باز کنید. برای لاگ فعلی، قبلی و رخدادها از جزئیات Deployment در کنسول استفاده کنید.

## Rollback نسخه‌ای نشان نمی‌دهد

فقط Buildهای موفق قابل انتخاب هستند. اگر پروژه نسخه موفق ندارد، ابتدا علت استقرار ناموفق را در کنسول بررسی کنید.

## Unauthorized یا Scope

- `Unauthorized`: Token منقضی یا لغو شده است؛ خروج و ورود دوباره را انجام دهید.
- `Scope`: نقش شما اجازه عملیات را ندارد؛ Owner یا Admin باید دسترسی را بررسی کند.

## اتصال به سرور اشتباه

برای سرویس عمومی، `paasta.server` باید دقیقاً `https://paasta.cloud` باشد. Token محیط‌های مختلف را با هم استفاده نکنید.

## گزارش امن خطا

نسخه افزونه و VS Code، سیستم‌عامل، نام فرمان و مراحل بازتولید را ثبت کنید. Token، کد ورود، `.env`، Credential، URL دارای رمز یا لاگ مشتری را منتشر نکنید.
