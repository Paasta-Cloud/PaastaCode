# Changelog

## 0.8.5

- مدیریت افزونه‌های رسمی Claude Code و Codex و انتخاب اتصال حساب شخصی یا پاستا از یک افزونه.
- اتصال کلید مخصوص ابزار با نگه‌داری خصوصی خارج از پروژه و بازیابی تنظیمات شخصی قبلی.
- بازکردن CLI روی دستگاه با تأیید پوشه و مجوزهای خود ابزار؛ فرمان وضعیت پروژهٔ پاستا با نشست فعلی افزونه.

## 0.8.4

- تشخیص پروژه از فایل بازشده در محیط چندپروژه‌ای، با جداسازی گفتگوها و درخواست‌های هر پروژه.
- نمایش اتصال GitHub یا GitLab و شاخهٔ انتشار هر پروژه از تنظیمات همان پروژه.
- پنل پیش‌فرض محیط آنلاین در سمت راست با فضای بیشتر؛ اندازه و جای انتخاب‌شدهٔ شما در ورودهای بعدی حفظ می‌شود.
- پایان وضعیت مبهم «در حال اتصال» با نمایش خطا و مسیر انتخاب پروژه یا تازه‌سازی.

## 0.8.3

- آماده‌سازی سورس هنگام بازگشت به هر پوشهٔ قبلی، همراه با نمایش پیش‌فرض پنل پاستا.
- اصلاح پوشهٔ شروع قدیمی محیط آنلاین، بدون جابه‌جایی فایل‌ها یا تغییر پوشهٔ پروژهٔ انتخاب‌شدهٔ کاربر.

## 0.8.2

- آماده‌سازی خودکار سورس پروژه‌های محیط آنلاین در پوشه‌های جدا، با حفظ فایل‌ها و تغییرات قبلی.
- فعال‌شدن پنل پاستا و CLI متصل به نشست کنسول، بدون ورود جداگانه یا ذخیرهٔ توکن دائمی.
- ورود به محیط شخصی بدون Workspace Trust؛ تنظیمات اعتماد VS Code دسکتاپ تغییر نمی‌کنند.

## 0.8.1

- ارسال درخواست سهمیه با کلید AI همان نشست در محیط آنلاین، همراه با حفظ اعتبارسنجی مجوز کنسول.
- ردکردن کلید متعلق به نشست دیگر و حفظ رفتار ورود دسکتاپ.

## 0.8.0

- یک افزونه و پنل برای مدیریت پروژه، انتشار و پاستاکد کامل، همراه با حفظ فرمان‌های قبلی.
- موتور ایجنت، تسک‌ها و تأیید ابزارها از کلاینت اصلی پاستاکد؛ بسته‌های بومی همراه با موتور و Node.
- ورود مشترک پاستاکد از نشست کنسول در محیط آنلاین؛ پایان دسترسی AI با خروج، لغو مجوز یا خاموش‌شدن محیط.
- حفظ اطلاعات دسکتاپ و جلوگیری از نصب دوبارهٔ افزونهٔ جدا از مسیر به‌روزرسانی.

## 0.7.0

- ورود خودکار از نشست کنسول در محیط آنلاین شخصی، با پایان دسترسی هنگام خروج از کنسول.
- بازکردن چند پروژه در پوشه‌های مستقل و حفظ تغییرات محلی هنگام جابه‌جایی.
- دریافت مخزن و Push از اتصال Git پاستا، بدون ذخیرهٔ توکن ارائه‌دهنده داخل پروژه.
- حفظ نام پروژه، مسیر ساخت و شاخهٔ متصل در انتشار از محیط آنلاین.

## 0.6.0

- دریافت سورس پروژهٔ آپلودی در پوشهٔ خالی، با حفظ نام پروژه و مسیر ساخت.
- انتقال پروژه به مخزن خصوصی GitHub یا GitLab و اتصال اختیاری مخزن به پاستا، با تأیید جداگانه.
- حفظ اتصال Git در انتشار بعدی و جلوگیری از بازنویسی تغییرات محلی هنگام اعمال پیشنهاد AI.
- محدودکردن تنظیمات سرور و CLI به تنظیمات کاربر و بررسی سرور صادرکنندهٔ توکن.

## 0.5.0

- نشان Activity Bar با فرم رسمی لوگوی پاستا جایگزین شد.
- انتشار پوشه فعلی به اقدام اصلی و همیشه‌قابل‌مشاهده پنل تبدیل شد و ورود افزونه، نشست CLI را نیز امن آماده می‌کند.
- Paasta Code به یک گفتگوی مستقل در تب Editor با انتخاب مدل، پیشنهاد شروع، Composer و نمایش زنده فعالیت منتقل شد.

## 0.4.0

- پنل مستقل پاستا به Activity Bar اضافه شد تا حساب، Paasta Code و پروژه‌ها همیشه یک جای مشخص داشته باشند.
- ورود امن از داخل بخش حساب با CTA واضح شروع می‌شود و وضعیت اتصال دائماً در Status Bar دیده می‌شود.
- walkthrough سه‌مرحله‌ای خود VS Code، بازکردن پنل، ورود با مرورگر و اولین ساخت با AI را معرفی می‌کند.
- بعد از ورود، پنل پاستا خودکار باز می‌شود و مسیر ساخت با AI مستقیماً پیشنهاد می‌شود.

## 0.3.0

- فایل‌های تغییرکرده را پیش از اعمال به‌صورت جداگانه انتخاب یا رد کنید.
- نتیجه بازبینی هر فایل در نشست پایدار Paasta Code ثبت می‌شود.
- لغو بازبینی هیچ فایلی را روی Workspace محلی تغییر نمی‌دهد.

## 0.2.0

- Paasta Code برای ساخت و اصلاح فایل‌های Workspace با مدل‌های فعال AI Coder اضافه شد.
- مراحل عامل کدنویسی به‌صورت زنده در Output نمایش داده می‌شوند.
- تغییرات پیشنهادی پیش از اعمال در Diff باز می‌شوند و تأیید صریح می‌خواهند.
- فایل‌های حساس، باینری و خروجی‌های build از زمینه مدل حذف می‌شوند.
