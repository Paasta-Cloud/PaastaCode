# PaastaCode | پاستاکد

رابط فارسی پاستاکد در VS Code، با یکانِ محلی در بستهٔ رسمی و وزیرمتن در ساخت متن‌باز. VSIX سیستم‌عامل خود را نصب کنید؛ بستهٔ مستقل، Node.js و موتورهای لازم را همراه دارد.

Powered by OpenCode. [پاستاکد](https://github.com/Paasta-Cloud/PaastaCode) فورک مستقل و متن‌باز [OpenCode](https://github.com/anomalyco/opencode) با مجوز MIT است و محصول رسمی OpenCode نیست.

۱. فایل VSIX مناسب سیستم‌عامل را با «Extensions: Install from VSIX» نصب کنید.
۲. برای نسخهٔ مستقل، تنظیم مسیر یا نصب Node.js لازم نیست. `paastacode.clientPath` فقط برای استفاده از سورس توسعه یا نصب سفارشی است.
۳. پوشهٔ پروژه را باز کنید، اعتماد به پوشه را بررسی کنید و از Command Palette دستور `PaastaCode: باز کردن پاستاکد` را اجرا کنید.
۴. با پاستا وارد شوید و سقف مصرف روزانه را تأیید کنید.

برای به‌روزرسانی از Command Palette، دستور `PaastaCode: بررسی و نصب به‌روزرسانی` را اجرا کنید. بررسی و نصب خودکار با تنظیم `paastacode.autoUpdate` کنترل می‌شود. بسته از انتشار رسمی دریافت و با SHA-256 آن تطبیق داده می‌شود. پس از نصب، بارگذاری دوبارهٔ پنجره با انتخاب شماست.

نسخهٔ ۰٫۲ در مسیر بتا است. فایل‌ها روی دستگاه اجرا می‌شوند و محتوای لازم برای مدل به API پاستا فرستاده می‌شود. ذخیرهٔ گفتگو در حساب اختیاری است. برای MCP و دیپلوی، «انتشار روی پاستا» را باز و اتصال جداگانهٔ انتشار را تأیید کنید؛ هزینه و سورس هر انتشار به بررسی و تأیید نیاز دارند. Remote SSH، محیط وبِ VS Code و انتشار فروشگاهی هنوز جزو خروجی تأییدشده نیستند.
