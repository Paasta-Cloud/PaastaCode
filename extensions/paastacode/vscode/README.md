# PaastaCode | پاستاکد

رابط فارسی پاستاکد در VS Code. این افزونه به نصب محلی PaastaCode و Node.js نیاز دارد.

Powered by OpenCode. [پاستاکد](https://github.com/Paasta-Cloud/PaastaCode) فورک مستقل و متن‌باز [OpenCode](https://github.com/anomalyco/opencode) با مجوز MIT است و محصول رسمی OpenCode نیست.

۱. بستهٔ PaastaCode را نصب کنید و `npm ci` را در پوشهٔ آن اجرا کنید.
۲. در تنظیمات VS Code مقدار `paastacode.clientPath` را روی مسیر کامل `bin/paastacode.mjs` قرار دهید.
۳. پوشهٔ پروژه را باز کنید، اعتماد به پوشه را بررسی کنید و از Command Palette دستور `PaastaCode: باز کردن پاستاکد` را اجرا کنید.
۴. با پاستا وارد شوید و سقف مصرف روزانه را تأیید کنید.

نسخهٔ ۰٫۱ توسعه است. ورود و ذخیرهٔ حساب به بخش سرور پاستاکد نیاز دارد. فقط VS Code دسکتاپ با پروژهٔ محلی هدف این نسخه است. فایل‌ها روی دستگاه اجرا می‌شوند و محتوای لازم برای مدل به API پاستا فرستاده می‌شود. ذخیرهٔ گفتگو در حساب اختیاری است.
