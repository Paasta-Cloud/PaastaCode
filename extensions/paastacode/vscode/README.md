# PaastaCode | پاستاکد

رابط فارسی پاستاکد در VS Code، با یکانِ محلی در بستهٔ رسمی و وزیرمتن در ساخت متن‌باز. VSIX سیستم‌عامل خود را نصب کنید؛ بستهٔ مستقل، Node.js و موتورهای لازم را همراه دارد.

Powered by OpenCode. [پاستاکد](https://github.com/Paasta-Cloud/PaastaCode) فورک مستقل و متن‌باز [OpenCode](https://github.com/anomalyco/opencode) با مجوز MIT است و محصول رسمی OpenCode نیست.

۱. فایل VSIX مناسب سیستم‌عامل را با «Extensions: Install from VSIX» نصب کنید.
۲. برای نسخهٔ مستقل، تنظیم مسیر یا نصب Node.js لازم نیست. `paastacode.clientPath` فقط برای استفاده از سورس توسعه یا نصب سفارشی است.
۳. روی آیکون پاستا در نوار کناری کلیک کنید. اگر پروژه‌ای باز نیست «باز کردن پوشه» را بزنید؛ پس از بررسی اعتماد به پوشه، پنل بومی پاستاکد باز می‌شود. دکمهٔ پاستاکد بالای تب ویرایشگر و فرمان `PaastaCode: باز کردن پاستاکد` در Command Palette هم در دسترس‌اند.
۴. با پاستا وارد شوید؛ صفحهٔ تأیید خودکار در مرورگر باز می‌شود. اشتراک فعال مستقیم متصل می‌شود. اگر اشتراک ندارید، از «اشتراک» بسته بخرید یا مصرف با کیف پول و سقف مشترک را صریحاً انتخاب کنید.

برای به‌روزرسانی از Command Palette، دستور `PaastaCode: بررسی و نصب به‌روزرسانی` را اجرا کنید. بررسی و نصب خودکار با تنظیم `paastacode.autoUpdate` کنترل می‌شود. بسته از انتشار رسمی دریافت و با SHA-256 آن تطبیق داده می‌شود. پس از نصب، بارگذاری دوبارهٔ پنجره با انتخاب شماست.

نسخهٔ ۰٫۲ در مسیر بتا است. فایل‌ها روی دستگاه اجرا می‌شوند و محتوای لازم برای مدل به API پاستا فرستاده می‌شود. ذخیرهٔ گفتگو در حساب اختیاری است. پیوست فایل، انتخاب کد ویرایشگر، نمایش زندهٔ خروجی و تغییرات Git در پنل یکپارچه‌اند. برای انتشار و مدیریت فضای ابری از وب یا برنامهٔ دسکتاپ استفاده کنید. Remote SSH، محیط وبِ VS Code و انتشار فروشگاهی هنوز جزو خروجی تأییدشده نیستند.
