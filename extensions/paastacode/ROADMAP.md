# نقشهٔ راه پاستاکد

۱. نسخهٔ اولیهٔ محلی: رابط فارسی، وب، Electron، CLI و VS Code با موتور مشترک، ورود دستگاه و ذخیرهٔ اختیاری متن گفتگو. پیاده‌سازی و تست محلی انجام شده است. سرویس حساب روی پاستا منتشر شده؛ ورود، کاتالوگ مدل، ذخیره و بازیابی با حساب‌های آزمایشی جدا در محیط واقعی بررسی شده‌اند. آزمون مصرف پولی و تجربهٔ کامل کاربر نهایی باقی است.

۲. انتشار متن‌باز: فورک رسمی OpenCode، مجوز MIT، انتساب روشن، اجرای مستقل و تست عمومی. سورس در [GitHub](https://github.com/Paasta-Cloud/PaastaCode) نگهداری می‌شود. ساخت موتور اختصاصی از سورس فورک و دریافت منظم تغییرات upstream گام بعدی است؛ فعلاً نسخهٔ ثابت npm اجرا می‌شود.

۳. توزیع: بستهٔ قابل نصب، امضای برنامه، به‌روزرسانی و تست Windows، Linux و macOS. افزونهٔ توسعه موجود است؛ انتشار فروشگاهی انجام نشده است.

۴. پیوستگی نشست: همگام‌سازی اختیاری، مدیریت تعارض، حذف گفتگو و سیاست نگهداری روشن. پشتیبان متن گفتگو جای Git یا فایل‌های پروژه را نمی‌گیرد.

۵. محیط اجرای ابری: فضای کاری مجزا، محدودیت منابع، دسترسی پروژه و صورتحساب. وب فعلی به پروژهٔ روی دستگاه متصل است.

۶. بتای عمومی: آزمون حساب واقعی، پرداخت و مصرف، بازیابی خطا و مستندات پشتیبانی پیش از فعال‌سازی عمومی.

۷. اتصال یکپارچه به MCP پاستا و انتشار مستقیم: ورود اختصاصی برای دسترسی انتشار، مشاهدهٔ پروژه‌ها و وضعیت استقرار، بررسی سورس و نمایش مقصد و هزینه پیش از تأیید، دیپلوی همین فضای کاری با بسته‌بندی امن و پیگیری نتیجه در وب، دسکتاپ، CLI و افزونه. درخواست مدل به‌تنهایی مجوز هزینه یا انتشار نیست؛ تأیید کاربر برای هر دیپلوی لازم است.

هدف جاری: تکمیل این مراحل و تحویل بسته‌های آمادهٔ نصب و اجرا برای مشتری. وزیرمتن همراه مجوز متن‌باز در تمام رابط‌ها قرار می‌گیرد. طراحی با senior-designer و نگارش با persian-writing انجام می‌شود؛ الگوهای مناسب VibeFarsi و FarsiUI با حفظ مجوزها در رابط مشترک به کار می‌روند.
