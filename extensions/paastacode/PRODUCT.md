# PaastaCode

PaastaCode / پاستاکد is Paasta's Persian coding-agent client. It uses the OpenCode engine, Paasta identity and AI catalogue, and explicit private account conversation backups. Developers work in a chosen local folder. The alpha is a local application; hosted execution and automatic cross-device repository transfer are later milestones. Never present local-only changes as cloud-saved.

The audience is Iranian developers and AI-assisted makers. The central task is requesting a code change, reviewing permissions and results, and continuing work without losing context. Prices are toman. No unrelated deployment capability is granted by login.

Platform: web, desktop, CLI, VS Code. Browser and desktop share the same UI; all clients must converge on the same workspace engine. Follow ../../DESIGN.md and the engineering handbook. The owner requests a familiar Codex-like developer workbench and licensed Yekan Bakh for Persian; keep isolated monospace for code. Open-source source builds retain the bundled Vazirmatn fallback when no licensed font is supplied. No invented logos or customer claims.

The complete product must include automatic/in-app desktop updates, extension/CLI updates and genuinely hosted workspaces that need no local installation. The currently delivered hosted interface still pairs with a local engine; do not present it as independent cloud execution.
