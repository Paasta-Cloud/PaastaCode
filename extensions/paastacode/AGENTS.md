# PaastaCode client

This independent Node.js client lives inside the upstream OpenCode fork. It uses the pinned npm engine; it does not import the upstream Bun workspace. From this directory run `npm run check` and `npm test`; for UI changes run `node test/browser.mjs` with Microsoft Edge installed and inspect desktop/mobile captures. Root Bun checks apply when modifying the upstream packages, not this standalone client.

Keep Persian RTL and LTR code/identifiers, explicit tool approvals, localhost capability protection, account isolation and real Paasta model prices. Model preferences may reorder only existing tool-capable catalogue entries. Never add a fictional live model or bypass account authorization. Preserve OpenCode attribution and MIT notices. Do not commit credentials, test-state directories or commercial fonts. `PAASTACODE_YEKAN_FONT` supplies an optional licensed local font.
