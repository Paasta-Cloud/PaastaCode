# پاستاکد | PaastaCode

فورک مستقل و متن‌باز OpenCode با مجوز MIT. [راهنمای اجرای پاستاکد](extensions/paastacode/README.md) و [نقشهٔ راه](extensions/paastacode/ROADMAP.md) را ببینید. Powered by OpenCode.

این نسخه وب محلی، دسکتاپ، CLI و افزونهٔ VS Code دارد. موتور فعلی همان بستهٔ ثابت و بدون تغییر OpenCode در npm است. ورود و ذخیره در حساب به انتشار بخش سرور پاستاکد نیاز دارد. فونت تجاری یکان در مخزن عمومی قرار ندارد و می‌توان مسیر فایل مجاز آن را تنظیم کرد.
