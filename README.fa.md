# پاستاکد | PaastaCode

فورک مستقل و متن‌باز OpenCode با مجوز MIT. [راهنمای اجرای پاستاکد](extensions/paastacode/README.md) و [نقشهٔ راه](extensions/paastacode/ROADMAP.md) را ببینید. Powered by OpenCode.

این نسخه وب محلی، دسکتاپ، CLI و افزونهٔ VS Code دارد. موتور فعلی همان بستهٔ ثابت و بدون تغییر OpenCode در npm است. سرویس حساب روی پاستا فعال شده و ورود، ذخیره و بازیابی با حساب آزمایشی در محیط واقعی بررسی شده‌اند. آزمون مصرف پولی و انتشار نصب‌کنندهٔ عمومی باقی است. فونت تجاری یکان در مخزن عمومی قرار ندارد و می‌توان مسیر فایل مجاز آن را تنظیم کرد.
