# پاستاکد | PaastaCode

فورک مستقل و متن‌باز OpenCode با مجوز MIT. [راهنمای اجرای پاستاکد](extensions/paastacode/README.md) و [نقشهٔ راه](extensions/paastacode/ROADMAP.md) را ببینید. Powered by OpenCode.

رابط تحت وب در [code.paasta.cloud](https://code.paasta.cloud) به فضای کاری روی دستگاه شما متصل می‌شود. از پوشهٔ کلاینت `npm start -- --hosted --workspace=/path/to/project` را اجرا کنید و ترمینال را باز نگه دارید. اجرای کاملاً ابری هنوز آماده نیست. سورس دسکتاپ، CLI و افزونهٔ VS Code و فونت متن‌باز وزیرمتن هم در مخزن قرار دارد. موتور فعلی همان بستهٔ ثابت و بدون تغییر OpenCode در npm است. ورود، ذخیره و بازیابی حساب پاستا با حساب آزمایشی در محیط واقعی بررسی شده‌اند؛ تکمیل آزمون‌های بسته‌های همهٔ سیستم‌عامل‌ها، مصرف پولی و انتشار امضاشده باقی است.
